# When a run owns execution

One mechanical custodian owns the target/socket/lock/store and serializes basic
input under original capacities/deadlines. It issues per-actor bearer capabilities;
no second writer is admitted. Retained actor names, process IDs, source images,
player claims or SQLite records cannot reconstruct authority after restart.

A live actor can observe/input through its current tools. A sealed actor can only
collect originals and read retained source/knowledge/context. It cannot capture
anew, mutate memory, run programs or create another handoff. User Pause and
partial/unknown delivery permanently stop input and cannot become a resumable transfer.

Handoff persists canonical immutable context before sealing. The driver verifies
its issuance/digest and actual old host/MCP group quiescence before minting a
successor under the original run/host/attempt limits. No game menu, save, identity
or memory assertion is an authority predicate. [Custody contract](../contracts/computer-control.md#computer-operations-and-custody).

## Permissions and player ownership

The lead owns design, integration, frozen source/admission, review and final
verification. The designated player owns goals/tactics, visual interpretation,
ordinary save/load/exit choices and fallible quantities/Work/outcome claims.
[Operator permissions](../operator-permissions.md) governs admitted project activity;
a frozen run is not permission for another paid allocation or publication.

Role restrictions are procedural, not OS security isolation. Explorers/reviewers
never send game input. Optional advisers/programs only propose. No player memory,
advice or stored context can bypass mechanical input custody.

## Designated campaign operator

The package freezes one player host adapter under the
[player host contract](../contracts/player-host.md). Give one explicitly designated player the
compact [guide](../player-guide.md), finite objective and current tool schema.
Keep routine engineering history/source searches outside its context. Preserve
ending capacity and, if permitted, meaningful unfinished work for a fresh successor.
Do not inject lead tactics or curate memory to manufacture a successful outcome.
Record interventions, failures and unknowns. [Campaign procedure](campaign-run.md).
