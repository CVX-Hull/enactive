# Native acceptance lane

Native compilation, synthetic fixtures and actual CDDA outcomes are separate
lanes. The [production report](../acceptance/2026-10-29-computer-control.md) records
scoped actual outcomes and remaining gaps. Before a new
native/control/usability claim, use a coherent committed checkpoint, frozen
project-local windowed target and original resources; retain failures.

1. Build the sole [mechanical adapter](../../tools/build_computer.py) with pinned local resources; preserve original bytes/build receipt and exact source/config hashes.
2. Exercise actual compiled socket/SDL delivery, backpressure/Pause, original expiry, duplicate IDs, EOF and inherited shared-lock lifetime. Record actual commands/results; fakes are separate evidence.
3. Freeze a fresh finite `campaign-run/3` package with its player host adapter. Qualify actual key, text and pointer effects during authentic useful player-selected work, not just delivered events or repeated PNGs.
4. Exercise current memory/program/correction/context and fresh actor handoff through useful work when in scope. No staged bad routine, lead tactics or automatic success inference.
5. Let the player save through visible controls, reload the same character in a fresh owned native-child session, and finish with a separate normal application exit. Preserve save-to-menu versus process-exit differences and player claims versus mechanical receipts.
6. Record scope, interventions, original unknowns, failures, actual cleanup, unrun gaps and exact source/route/native bytes. Independent review and protected CI remain required for formal acceptance.

Do not edit saves, inspect hidden engine state, bypass input checks or repair source
while the actor/game is live. A later source repair never relabels an earlier run.
The [proof report](../acceptance/2026-10-29-basic-computer-control.md) is earlier
scoped evidence, not production acceptance. Geometry/resize, Unicode/IME,
actual-human takeover and second-game qualification remain explicit gaps.

## Passive skill acceptance

Old semantic movement/planner contracts are retired. Optional player programs
receive actual image views and propose the same basic controls; their usefulness
and corrections need authentic observed effects, not a passing evaluator or
synthetic displacement. No helper result grants custody or certifies success.
