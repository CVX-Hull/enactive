research, programs/practice, campaigns/runtime and cleanup. The lead inspected their
evidence against the saved tracker, current contracts and source. Independent review
confirmed that no existing leaf was executable as written, but identified a useful
repair that the initial sweeps had missed: the process producer returns `[0,0]` for

admissions, while the current contract describes these as 95% intervals.

The lead reproduced those boundary calculations directly with the existing seeded
bootstrap: two admissions with denominator one each produce `[0,0]`, `[1,1]`, and
`[0,1]` for zero, all-success and mixed observations respectively. This is an arithmetic
reproduction, not new labels, independent source evidence or interval calibration.
The [measurement review](2026-11-16-experiment-measurement-review.md#outcome-instruments-and-uncertainty)
already explains why zero-only resampling cannot establish a zero population rate.

artifacts. It owns a prospective report-contract migration with explicit unsupported
range states, descriptive resampling labels and honest source-unit limitations.
Separate clean-context review approved its bounded producer/test/current-contract
ownership. That review found one migration edge: the old process-contract documentation
fragment must keep resolving for historical evidence links. The brief now explicitly
preserves that fragment without introducing a schema compatibility alias.
