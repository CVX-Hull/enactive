renderer/serializer doubles. This small fixture owns no runtime framework; native
encoding and gameplay require separate actual qualification. Focused tests and source review remain
separate from actual game evidence and final protected CI.

Keep CDDA's ordinary UI/activities, existing native bridge, controller, single
MissionRuntime, strict JSON Schema validation, SQLite ledger/evidence archive,
official MCP SDK and Git/GitHub. No new input executor, log/history store, vector
database, graph service, generic agent framework or paid model API is selected.

its SDL2 backend polls/captures/warps the physical pointer. The native worker must

is distinct from the core library. No dependency is adopted for this first slice:

not covering the game's mixed UI. Retain the existing label shortcuts and extend
the bridge's ordinary event handling. Revisit a library for a demonstrated gap;
