## Design and reuse

Keep the existing architecture, composer, SDK staging, single writer and explicit
Observe. In a selected active snapshot with an idle prompt and no lifecycle or
activity phase, a refused new root explains the supported explicit observation
and subsequent decision. Observe may report ordinary macro closure; the caller
must inspect returned state. The error performs no observation, input, closure,
retry or authority change. Whole-mission capacity is not the local-root allowance.
Paused/pending/other-phase cases keep their separate refusal behavior. The MCP's
pure-unsubmitted guidance now respects a specific error's next step rather than
always directing argument correction. Existing-stage uncertainty still requires
original collection; the pre-staging proof and all costs are unchanged.

Extend only the existing decision projector's typed source/context slots. Omit
known source-reference technical metadata and the context configuration's native
hash. Preserve selection IDs, observation content, images, geometry, uncertainty,
Work, claims, procedures and unknown authored fields. No recursive name filter,
new metadata endpoint, cache, executor, policy framework or menu catalogue.
The raw SDK source response and original context response remain complete.
Snapshot detail is exact to its chosen cached snapshot; it does not supply a
foreign historical source's metadata. Historical binding proofs remain available
to machine/engineering callers through the existing SDK source API and evidence.
The player needs semantic/image evidence, not manually transcribed integrity hashes.

The system responsibilities and flow are unchanged; the component view is the
appropriate review level. Another architecture diagram would repeat that view.
Current guide/protocol/setup/component pages own behavior; this brief retains the
rationale, not another live tracker or attempt log.

## Migration and assurance

MCP6.1.0 and player-view/5 are the current implementation/presentation pair.
Migrate current tests and documentation together, retiring already loaded older
producer actors for new input. There is no old-format reader or compatibility
shim. Canonical mission/11, native6, procedure3, persisted evidence and tool input
shapes are unchanged. Frozen older records remain historical evidence.

Focused checks cover pure composition and actual MCP no-stage/no-submit refusal,
Pause/pending/other-phase negatives, existing ordinary macro closure, typed-only
projection, unchanged full records and real HTTP/SDK source/context responses.
Independent integration review and the applicable protected CI profile qualify
source/publication; exact merged-main validation remains required. No native
build is needed for these adapter-only changes. Actual fresh-host ergonomics,
organic recovery/normal ending and useful cadence need separately frozen evidence.
Neither byte reduction nor a passing fixture is a responsiveness/campaign claim.

Retained CLI JSONL identifies tool start/completion and result content, without
per-event timestamps. Existing host start/end receipts are process bounds, not
model result receipt or evidence sufficiency. Do not reconstruct timestamps from
file order, captures or inference guesses. A future assessment must disclose any
selected-capture/display proxies and missing joins under [evaluation](../evaluation.md).
